# Vehicle License

An AI-powered insurance claims automation system that processes FNOL (First Notice of Loss) documents in PDF and TXT formats. The application extracts claim information, validates mandatory fields, classifies claim types, and intelligently routes claims to the appropriate workflow using rule-based decision logic and AI reasoning.

## Overview

Vehicle License is designed to reduce the manual effort involved in insurance claim intake and triage. It is built for organizations that receive First Notice of Loss (FNOL) submissions in a variety of formats and want a faster, more reliable way to extract critical information and route claims.

Using structured validation rules and AI-assisted reasoning, the system helps teams:

- Extract claim details from PDFs and TXT documents
- Detect missing or invalid required information
- Classify claim types based on contextual inputs
- Route claims to the appropriate workflow
- Support faster downstream processing and review

## Key Features

- FNOL document intake from PDF and TXT files
- Claim field extraction and normalization
- Mandatory field validation
- Claim classification logic
- Rule-based workflow routing
- AI-assisted decision support
- Scalable foundation for insurance operations automation

## How It Works

1. Upload or ingest an FNOL document.
2. The system extracts key claim data.
3. It checks for mandatory fields and validation issues.
4. The claim is classified using business rules and AI-driven inference.
5. The claim is routed to the appropriate processing workflow.

## Project Goals

This project aims to streamline insurance claims intake while improving reliability, consistency, and operational speed. It is particularly useful for teams that need to automate document-driven claim handling without sacrificing compliance or accuracy.
